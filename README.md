# 码序 · QR Ledger

移动端二维码批量扫描记录工具，纯静态网页，无需构建或后端。

## 功能

- 手机摄像头连续扫码，自动保存与去重
- 按首次录入顺序生成 001、002… 流水编号
- 暂停/继续、搜索、备注编辑、删除（编号不重排、不复用）
- HTTP/HTTPS 二维码可点击并在新标签页打开，自动标记“已打开”
- 独立的“已绑定实名”开关，需手动确认，支持撤销；旧记录默认未打开、未绑定
- 浏览器本地存储，刷新后保留记录
- UTF-8 BOM CSV 导出，包含编号、原始内容、时间、备注、已打开和已绑定实名状态

CSV 导入兼容旧版四列、六列及新版八列导出文件，恢复备注、状态与时间；按二维码内容去重，不覆盖已有记录。编号无冲突时保留，冲突时分配新编号。导入整份校验通过后才保存。请使用 UTF-8 编码。

首次打开链接时记录打开时间，重复打开不会覆盖。开启实名绑定时记录绑定时间，关闭时清除，重新开启记录新的绑定时间。时间显示在记录中，CSV 以 ISO 时间格式保存以保留时区。旧数据缺少历史时间时显示“未记录”，不补造时间。

点击右上角二维码图标，可显示当前网站地址的二维码，供其他人扫码访问；不会分享本机记录。二维码在本地生成，无外部二维码服务请求。需使用他人可访问的部署地址，本机 localhost 地址无法供他人访问。

## 运行与部署

本地调试：在仓库根目录运行 `python3 -m http.server 8000`，电脑打开 `http://localhost:8000`。

手机摄像头需要 HTTPS。将仓库根目录部署至 Netlify、Cloudflare Pages 或 GitHub Pages，无需构建命令。识别库已随源码提供，无需外部 CDN。

## 文件

- `index.html`：页面结构
- `style.css`：响应式样式
- `app.js`：摄像头、记录管理、持久化和导出逻辑
- `vendor/qrcode.js`：qrcode-generator 1.4.4（MIT，许可声明见文件头），本地生成网站分享二维码
- `vendor/jsQR.js`：jsQR 1.4.0（Apache-2.0，许可证见 `vendor/LICENSE-jsQR`）

## 使用与数据

通过 Android Chrome 或 iOS Safari 打开，点击开始扫描并授权摄像头。数据保存在当前设备、当前浏览器、当前网站域名下，不上传云端。清除浏览器数据会删除记录，请及时导出。切换部署域名不会自动迁移历史记录。

CSV 编号使用前置制表符帮助 Excel 保留前导零；可能被识别为公式的内容使用前置单引号防护，应用内保留原始内容。不同表格软件的显示行为可能不同。

## 验证

运行 `node --test tests/app.test.cjs`，覆盖链接协议限制、打开状态与绑定状态独立保存、CSV 往返、旧格式兼容、错误格式拦截和去重合并。

已通过 500 条记录的逻辑测试，覆盖去重、删除后继续编号、备注持久化与 CSV 转义。手机摄像头识别效果、iOS Safari 兼容性和震动反馈仍需真机验证。
